# AGENTS.md

## What this repo is

TWRP device tree for Google Pixel 6 Pro (raven). Auto-generated by SebaUbuntu's TWRP device tree generator. This is **not** a standalone project -- it lives inside an Android source tree at `device/google/raven/`.

## Build

Requires a full AOSP/TWRP build environment. This repo is cloned into the tree via:

```bash
repo init -u https://github.com/minimal-manifest-twrp/platform_manifest_twrp_aosp -b twrp-14.1 --depth=1
repo sync -j$(nproc --all) --force-sync
mkdir -p device/google/raven
# copy this repo's contents into device/google/raven/
```

Then build:

```bash
source build/envsetup.sh
lunch twrp_raven-ap2a-eng
mka bootimage recoveryimage -j$(nproc --all)
```

Outputs land in `out/target/product/raven/` (boot.img, recovery.img).

## Key files

| File | Purpose |
|---|---|
| `BoardConfig.mk` | Board-level config: kernel, partitions, A/B, TWRP settings, AVB |
| `device.mk` | Product packages (boot HAL, update_engine, etc.) |
| `twrp_raven.mk` | Top-level product makefile, inherits TWRP common config |
| `AndroidProducts.mk` | Registers lunch combos (`twrp_raven-{user,userdebug,eng}`) |
| `recovery.fstab` | Partition mount table for TWRP recovery |
| `recovery/root/` | Rootfs overlay: init scripts, touch kernel modules, HAL manifests |
| `prebuilt/` | Prebuilt kernel, dtb.img, dtbo.img |
| `extract-files.sh` / `setup-makefiles.sh` | Vendor blob extraction scripts (require AOSP `extract-utils`) |

## Gotchas

- **Prebuilt kernel**: `TARGET_FORCE_PREBUILT_KERNEL := true`. Do not modify `TARGET_KERNEL_SOURCE` expecting it to build the kernel -- it uses `prebuilt/kernel`.
- **Anti-rollback hack**: `PLATFORM_SECURITY_PATCH` and `PLATFORM_VERSION` are set to fake future values (`2099-12-31`, `17.0.0`) to bypass rollback checks. Do not "fix" these.
- **A/B device**: Recovery is embedded in boot (`BOARD_USES_RECOVERY_AS_BOOT := true`).
- **fstab has dual entries**: Each partition has both erofs and ext4 lines; TWRP tries both.
- **CI branches**: `A17` and `A14` (see `.github/workflows/build-twrp.yml`).
- **USB/ADB**: GS101 only supports USB ConfigFS (no legacy `android_usb`). `TW_EXCLUDE_DEFAULT_USB_INIT := true` skips TWRP's default init. Full configfs gadget setup with `ffs.adb` is in `init.recovery.raven.rc`.
- **Touch**: Touchscreen modules (`goog_touch_interface.ko`, `sec_touch.ko`) are loaded via `insmod` in `init.recovery.raven.rc`. They live in `recovery/root/system/modules_touch/`.
- **Data decryption (FBE)**: The `/data` partition uses hardware-wrapped keys (`wrappedkey_v0`) on Tensor. Both `recovery.fstab` and `recovery/root/system/etc/twrp.flags` must have matching `fileencryption=aes-256-xts:aes-256-cts:inlinecrypt_optimized+wrappedkey_v0` and `metadata_encryption=aes-256-xts:wrappedkey_v0`. TWRP splits `fileencryption` on the first colon to set `fbe.contents`/`fbe.filenames` properties. KeyMint and Gatekeeper HAL services must be started in `init.recovery.raven.rc` for hardware key unwrapping.

Makefile-only repo. Follow existing AOSP makefile conventions. No tests, no linter, no formatter to run.
